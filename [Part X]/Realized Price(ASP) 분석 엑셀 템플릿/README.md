# Realized Price (ASP) 전년 대비 분석 엑셀 템플릿

세일즈 데이터를 붙여넣으면 **전체 / 업체별 ASP(매출액 ÷ 수량)를 전년과 비교**해 주는 엑셀 파일입니다.
필요한 열을 **열 위치가 아니라 헤더명으로 찾기 때문에**, 추출 데이터에 다른 열이 아무리 많아도 그대로 붙여넣으면 됩니다.

- 파일: `RealizedPrice_ASP_템플릿.xlsx` (가상의 예시 데이터 1,025행 포함)
- 필요: Excel 2021 또는 Microsoft 365 (업체 목록 자동 생성에 `UNIQUE` 함수 사용)

## 사용 방법

1. **RAW 시트**: Ctrl+A → Delete로 예시 데이터를 지우고, 추출 데이터를 A1에 헤더 포함 그대로 붙여넣기
2. **설정 시트** (노란 칸만 입력)
   - ② 열 매핑: 기간 / 업체 / 수량 / 매출액에 해당하는 헤더를 드롭다운에서 선택
   - ③ 비교 기간: 당해 시작·종료 입력 → 전년은 자동으로 1년 전 기간
   - ④ 필터(선택): 사업부, 제품군, 통화, 단위 등으로 범위 좁히기 (`<>값` = 제외, `값*` = ~로 시작)
   - ⑥ 데이터 점검이 모두 ✔ 인지 확인
3. **업체별 ASP 시트**: 맨 위 `전체` 행 = 전체 ASP 전년 대비, 아래 = 업체별 (정렬 기준은 설정 ⑤)

## 시트 구성

| 시트 | 내용 |
|---|---|
| 사용방법 | 사용 순서, 계산 기준, 주의사항 |
| 업체별 ASP | 전체 + 업체별 매출액·수량·ASP (전년 / 당해 / 증감 / 증감률) |
| 설정 | 헤더 행 번호, 열 매핑, 비교 기간, 필터 3개, 정렬, 데이터 점검 |
| RAW | 데이터 붙여넣는 곳 |
| _calc (숨김) | 업체 목록·합계·정렬 계산용 |

## 계산 기준

- ASP = 매출액 합계 ÷ 수량 합계 (기간·업체별로 먼저 합산 = 수량 가중 평균 단가)
- ASP 증감 = 당해 ASP − 전년 ASP, 증감률 = 당해 ASP ÷ 전년 ASP − 1
- 기간 열은 날짜, 연도(2026), 연월(202609) 숫자 모두 가능 (텍스트로 된 날짜는 제외되므로 점검 시트에서 확인)
- 업체 ASP 증감에는 가격 변화와 제품 믹스 변화가 함께 들어 있음 → 제품군별로 보려면 필터 사용
- 반품(− 수량), 단가 소급 정산(수량 0, 금액만 있는 행)도 그대로 합산
- 업체는 최대 3,000개까지 표시

## 템플릿 다시 만들기

```
pip install openpyxl pandas numpy
python make_template.py
```

`CAPACITY`(최대 업체 수), 기본 헤더명, 기본 비교 기간 등은 `make_template.py` 상단에서 바꿀 수 있습니다.
다시 만든 파일은 엑셀에서 처음 열 때 값이 계산됩니다.
